# Release 检查界面

2026-10-20，按 `workspaces/active/20261020-ui-layout/UI_REDESIGN_PLAN.md` 实施。

## 页面

顶栏只保留名称、文件数、示例标签、四个模块的计算状态，以及配置和导出入口。五个页签为综合总览、Bin1 CPK、CGM、Site Diff、Outlier，徽章均按测项计数。

左边是筛选、搜索、测项表和分页，约占 38%；右边是判断说明、图表和 Remark，约占 62%。左表可收窄。窗口低于 1280px 时上下排列。总览默认筛选需关注，右边逐行列出各模块的值、状态、来源和判断原因；问题模块带缩略图，点击后进入对应模块。

## 配置

“数据源与计算配置”打开抽屉。文件表包含阶段、温度、site 数、记录数、测项数和四个角色列。CPK、CGM、Site Diff 各选一份；Outlier 可选多份。拖入、移除、清空、使用示例及独立范围选择均保留。

范围修改在重新计算前不改变旧结果；结果变灰，导出禁用。全部成功后收起抽屉，失败或取消时保持打开，失败文件标红。计算过程中显示阶段并可取消。

## 图表与观察

- CPK：直方图叠加核密度；Q-Q、分 site 箱线、Wafer，无坐标时改为测试次序。
- CGM：Cg / Std 柱；测试次序、去均值波动、site 统计。规则和家族入口在左表上方，家族视图保留矩阵、排序、分页和 CSV 导出。
- Site Diff：按原规则用测试次序或小提琴作主图，另一张图、直方图和 site 统计作对照。诊断条保留 gate 和三个参数。
- Outlier：参考区间；命中测项、候选热力、Wafer 候选位置，无坐标时显示候选表。可按测项或候选芯片查看，保留单条证据和定位复制。

每个模块共用 site 选择，换模块时清除。前三个模块的四张图来自同一图表响应；切测项取消过期请求。核密度、Q-Q、小提琴只画样本形状，不改全量统计。测项表中的额外统计在点选后读取并缓存，尚未读取时显示“—”。

单位缺失的测项继续计算和判断，在当前测项旁提示“单位缺失”，报告中保留该提示，不因此改变通过、风险或未达标状态。

Remark 默认显示十个观察标签、一句补充和保存下一项；展开后显示建议检查、最终 Remark、状态、英文预览、家族应用及撤销。保存直接视为确认，前三个模块发送原接口要求的 `confirmed: true`。有未保存修改时，换测项、换模块和重算会提示。重新计算不复制旧观察。

当前后端观察接口仅接受 CPK、CGM、Site Diff。Outlier 观察因此保存在前端当前会话，并加入报告 JSON 的 `outlier_observations`。导出观察时，原观察 Excel 照常下载，另带一份 `outlier-observations.xls`（Excel XML）。未改后端接口。

## 导出与验证

顶栏导出菜单按本次结果、当前测项、原始数据、家族矩阵分组。总览不提供当前图组导出；进入对应模块后可用。当前视图和完整范围均导出四张图，家族矩阵单独导出 CSV。

前端测试、正式构建和 STDF 接口检查记录见 `workspaces/active/20261020-ui-layout/evidence/`。测试文件为项目内 `browser-smoke.stdf`，不是客户生产数据；真实大文件的最终人工验收仍需由工程师完成。
